# Supports TV5MONDE pour usage local

Les PDF et MP3 de TV5MONDE ne sont pas inclus dans le dépôt public. TV5MONDE les propose au téléchargement sur [sa page des livrets TCF](https://apprendre.tv5monde.com/fr/article/les-livrets-dentrainement-au-tcf-r-avec-tv5monde). Pour utiliser les tests blancs hors connexion, téléchargez les 17 paires de fichiers et placez-les dans ce dossier avec les noms attendus par `tcf-data.js`.

Le dépôt n’accorde aucun droit de redistribuer ces supports. Sans ces fichiers, les entraînements originaux de l’application restent utilisables, mais les livrets et les tests blancs locaux ne fonctionnent pas.
